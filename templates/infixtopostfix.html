How it works

  • Operand (A, B, 5…) → send it straight to the output.
  • ( → push it onto the stack.
  • ) → pop to the output until you reach (, then remove the (.
  • Operator → pop operators with higher (or equal) precedence first, then push the new one.
  • At the end, pop everything left on the stack to the output.
  • Value: if the expression has only numbers, read the postfix left to right. A number is pushed; an operator pops two numbers, calculates, and pushes the answer.

Precedence: ^ (highest, right to left) > * / % > + -. The stack is built from linked-list Nodes (stack.py): push adds a new top node, pop removes it, and peek only looks at it.
